# Osama & Eman Wedding Invitation

## Build
- Replace the blank page with one mobile-first scrolling invitation in the requested sequence: opening envelope, letter reveal, invitation card, countdown, details, venue, RSVP/wishes, and footer.
- Create the complete romantic vintage-luxury visual system with custom SVG calla lilies, hydrangeas, lace, gold ornaments, villa line art, grain, petals, and sparkles—no photography.
- Add refined motion for the envelope opening, letter reveal, record playback, scroll entrances, florals, and ambient particles while respecting reduced-motion preferences.

## Guest Experience
- Add music controls that begin only after opening the envelope, loop, remember mute state, pause while the tab is hidden, and resume appropriately. The controls will be ready but silent until the licensed audio file is uploaded.
- Add a Cairo-time countdown, Google Calendar action, downloadable calendar file, and venue action. The location action will use a Google Maps search fallback until the exact shared link is provided.
- Add accessible RSVP and wishes dialogs, live public response lists, validation, length limits, and one submission per device.

## Data and Configuration
- Use Lovable Cloud tables for shared RSVP and wishes data, protected by public read/create-only rules and live updates.
- Keep names, date, venue, address, map link, and song source together in one configuration file.
- Add a custom illustrated social preview and invitation-specific sharing metadata.

## Verification
- Check the invitation at mobile and desktop sizes, open the envelope, exercise music controls, validate countdown/calendar actions, submit and display RSVP/wish entries, and confirm no horizontal overflow or browser errors.
